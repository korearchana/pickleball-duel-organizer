# Pickleball Duel Organizer PWA

A static Progressive Web App for fair pickleball rotations.

## What it does
- Any number of players.
- Reservation length, game length, and number of courts.
- Maximum time each player should spend at the court (default 120 minutes).
- Staggers arrival windows across the reservation.
- Shows each player's arrival, departure, number of games, and playing minutes.
- Tries to equalize games while reducing repeated pairings.
- Works offline after first load.

## Install on iPhone
1. Publish this folder on an HTTPS website.
2. Open the site in Safari.
3. Tap Share → Add to Home Screen.

## GitHub Pages
Create a repository, upload all files, and enable GitHub Pages from Settings → Pages. GitHub Pages provides HTTPS for Pages sites.

## Important
This is a local-only app. Player names stay in the browser and are not sent to a server by the app.
